# ReadLog

Уеб приложение за следене на прочетени книги.

## За кого е
За хора, които четат редовно и искат да помнят какво са прочели и какво мнение им е останало.

## Какъв проблем решава
Читателите забравят заглавия, впечатления и колко книги са прочели. ReadLog държи всичко на едно място: библиотека с книги, лична оценка и бележка, годишна цел и статистика по месеци.

## Функционалности
- Добавяне, редакция и изтриване на книги
- Търсене по заглавие
- Оценка и бележка към книга
- Статус „чета" / „прочетена"
- Годишна цел за брой книги
- Графика на прочетеното по месеци

## Процес на работа
- Задачите се водят в Jira (ключ SP), Kanban борд с WIP лимит 2.
- Всеки тикет има бранч `SP-<номер>-<описание>`.
- В `main` се влиза само през Pull Request със заглавие `SP-<номер> ...`.
- При merge Jira Automation премества тикета в Done.
